Sharing the file

What does the reader need?

A modern browser. The file works offline, including its images, colour menu and section navigation. External source links need a connection when followed.

How do I send it?

Send it through a service that accepts HTML attachments, or upload it somewhere you control. Some email services block HTML files. Use Print / PDF in the document if a PDF is easier to send.

Is the document uploaded to this website?

No. This page contains a fixed example. Your document is created in your chat session. The plugin does not publish it or send it to this website.

Can I change the layout after exporting?

Ask ChatGPT to render the same content with another layout. It creates a separate HTML file. Colour choices are available inside each exported file.
