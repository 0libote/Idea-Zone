A few good questions

Before you share.

Does the reader need ChatGPT?

No. An exported Idea Zone is an ordinary HTML file. Anyone can open it in a modern browser without installing the plugin or signing in.

How do I send it to someone?

Send the HTML file through a service that allows HTML attachments, or upload it somewhere you control. Some email services block HTML attachments; printing to PDF is a useful alternative. The plugin doesn’t automatically host or publish your documents.

Can it really include multiple pages?

Yes. Pages are named sections inside one HTML file, with navigation to switch between them and a “Read all” option. There are no extra files, routes, or folders for the reader.

Will it work offline?

Yes. Formatting, navigation, and embedded images work without internet access. Source links still need a connection when you follow them. No external fonts, scripts, or stylesheets are needed.

Can I use my own images?

Yes. Supply the images in your conversation. Idea Zone embeds supported raster images in the HTML rather than linking to remote files. Larger images make the document larger, so smaller versions are often better for sharing.

Is my conversation uploaded here?

No. This landing page displays a fixed example. The plugin creates your document using the tools in your chat session and does not send it to this website. You decide what to share and where to send it.
