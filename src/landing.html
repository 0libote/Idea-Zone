__PLUGIN_STATUS__

File creation requires a chat with file tools. Plugin access depends on your account and workspace settings.

  1. Install, then start a chat

    Open the plugin link and select Install when available. Start a new chat after installing.

  2. Choose what to include

    Use the conversation or supply notes and images. Say who the document is for and what they need to know.

  3. Download and share

    Choose Brief, Editorial or Report. Check the document, adjust its appearance and send the HTML file or print a PDF.

Use Idea Zone to make a Brief from this discussion. Include the images, compare the options in a table, and finish with a checklist of next steps.

Before you send it.

What does the reader need?

A modern browser. Embedded images and fonts, section navigation and Appearance controls work offline. Source links need a connection when followed.

Can I change the layout?

Brief, Editorial and Report are different templates. Ask ChatGPT to render the content in another layout to get a separate HTML file. Colours and fonts can be changed inside each file.

Can I email the HTML file?

Use a service that accepts HTML attachments or host the file somewhere you control. Some email services block HTML files. Print to PDF if that is easier to send.

Does this website receive my document?

No. It shows fixed examples. Your document is created in your chat session, and the plugin does not upload or publish it here.
